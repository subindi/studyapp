# 스스로 · 아기 용 전체 화면 제작 패키지

작성일: 2026-10-07 / 버전: 아기 용 스킨 1.0

샘플 이미지의 아기 용과 정원 분위기를 기존 전체 화면에 적용한 개발 인계용 디자인입니다.
기존 아침 디자인의 기능 흐름과 제품 정책을 기준으로 합니다. 이 패키지부터 아기 용 스킨 적용이 현재 요청 범위입니다.
이전 기본 디자인 인계 v1.1의 ‘캐릭터를 적용하지 않는다’는 안내는 이번 패키지에는 적용하지 않습니다.

## 화면 보기

압축을 푼 뒤 index.html을 브라우저에서 엽니다. 핵심 흐름·시작과 상태·부모 PC를 선택하세요.
상단의 화면 선택 버튼으로 시윤·승윤·부모, 처음 시작·모드 전환·예외·알림·태블릿 시안을 전환합니다.
실제 버튼을 눌러 순서 선택·타이머·도움·완료·부모 확인·회고를 확인할 수 있습니다.
체험 PIN은 1234입니다. 설정 화면에서 새 PIN을 만들면 해당 파일 안에서는 새 PIN을 사용합니다.
모바일·태블릿·PC 레이아웃과 시스템 다크 모드 스타일을 포함합니다.

## 파일 구성

- designs/: 브라우저에서 바로 보는 한글 동작 시안 3개.
- source/: 편집 가능한 전체 화면 HTML/CSS/JavaScript 원본 3개.
- assets/dragon-atlas.png: 투명 배경 캐릭터 6상태 원본, 3열×2행.
- assets/garden.svg: 편집 가능한 정원 배경.
- assets/skin.css: 공통 색상·카드·버튼·캐릭터 배치·반응형·다크 모드.
- assets/skin.js: 상태에 맞는 캐릭터와 짧은 격려 문구.
- assets/design-tokens.json: 개발용 디자인 값.
- assets/font.css 및 assets/fonts/: 한글·아이콘 폰트와 라이선스.
- docs/: 제품 정책, 화면 범위, 기본 디자인 규칙, 스킨 상세 명세, 클로드 요청문.
- previews/: 확인용 화면 이미지. 이미지보다 HTML과 제품 정책을 구현 기준으로 사용합니다.
- CLAUDE.md / CLAUDE_UPLOAD.txt: 클로드 코드와 일반 대화용 안내.

## 클로드로 전달

일반 클로드에는 CLAUDE_UPLOAD.txt를 첨부하고 docs/04-claude-start.txt를 요청문으로 전달하세요.
이미지 자산을 적용하려면 이 폴더 전체를 함께 전달합니다. 통합 TXT에는 PNG 바이너리가 포함되지 않습니다.
Claude Code에서는 압축을 푼 폴더를 열고 CLAUDE.md부터 읽도록 요청합니다.

## 제작 범위

실제 사용할 캐릭터 자산과 편집 가능한 디자인 파일을 포함합니다. 운영 앱 구현은 아직 아닙니다.
로그인·서버 저장·부모 권한 검증·실제 알림·다른 앱 제한은 연결되어 있지 않습니다.
시안별 임시 데이터는 서로 공유되지 않으며 새로 열면 초기화됩니다. 주간 기록은 예시입니다.
별도 스킨 상점·캐릭터 진화·포인트·애니메이션·자동 기기 잠금 기능은 추가하지 않았습니다.
실제 서비스 출시 전 접근성·성능·실기기 확인이 필요합니다.
