# 아기 용 스킨 제작 명세

## 방향

샘플 이미지의 둥근 민트색 아기 용, 잎 모양 뿔, 작은 날개, 볼 홍조, 미색 바탕과 작은 정원을 따른다.
정원은 글자 뒤에 깔지 않고 캐릭터 영역에만 사용한다. 화면 제목·버튼·상태는 실제 한글 텍스트다.
부모 설정·입력·오류 화면은 작은 캐릭터를 사용한다. 형제 비교·벌점·캐릭터 시듦 표현을 넣지 않는다.
기본 원본의 이모지 아이콘은 동작 참고용으로 유지했다. 운영 자산이 필요하면 일관된 라이선스 아이콘으로 교체한다.

## 캐릭터 자산

dragon-atlas.png: 1536×1024, RGBA 투명 PNG, 3열×2행. 셀 512×512.

한 장에서 CSS background-size:300% 200%, background-position으로 각 포즈를 선택한다.

| 도움 | 어려움 선택, 해결 제안, 부모 도움 요청 | 도움/기다림 캐릭터, 차분한 문구 |

| 자유시간 | 잠김, 사용 가능, 타이머, 종료 | 휴식 캐릭터, 학습 타이머와 문구 구별 |

| 부모 모바일 | 오늘, 자녀 상세, 오늘만 조정, 반복 등록·수정, 설정, 리포트 | 작은 정원 헤더, 입력과 관리 중심 |
| 시작 | 소개, 가족/아이, 자율권, 첫 할 일, PIN, 완료, 아이 추가 | 인사 캐릭터, 입력 단계는 작게 |
| 모드 전환 | 아이 선택, 부모 PIN·오류·복구, 부모/아이 진입 | 인사/기다림 캐릭터, 한글 잠금 안내 |
| 예외·저장 | 할 일 없음, 확인 대기, 되돌리기, 종료, 저장·실패·오프라인 | 상태별 캐릭터, 행동과 오류 안내 유지 |
| 알림 | 도움 요청, 전체 완료, 리포트 진입 | 작은 캐릭터, 해당 화면 이동 유지 |
| 태블릿 | 오늘 순서 + 현재 학습 | 2열과 작은 독서/축하 헤더, 좁으면 1열 |
| 부모 PC | 오늘, 승인, 도움, 반복, 성장, 설정, 잠금 | 작은 상단 헤더와 사이드 캐릭터 |

## 디자인 값

주요 버튼은 어두운 초록 #47754E, 학습 행동은 파랑 #2C689A를 사용해 흰 글자 가독성을 확보한다.
배경 #FFFAF0, 본문 #253D36, 카드 #FFFEF9, 테두리 #E6DFCA, 연초록 #EAF2DF.
캐릭터 헤더 기본 높이 약 164px, 작은 헤더 약 90px. 모바일 본문 16px, 버튼 최소 44px.
카드 20–24px, 주요 버튼 24px, 화면 프레임 30px. 공통 값은 design-tokens.json과 skin.css에 있다.
시윤의 일부 화면은 작은 헤더로 줄인다. 부모 PC 사이드 캐릭터는 640px 이하에서 감춘다.
다크 모드는 본문·카드·테두리를 어둡게 바꾸고 정원에 어두운 혼합을 적용한다. 캐릭터 원본은 그대로 쓴다.

## 구현 주의

캐릭터의 축하가 자유시간 승인이나 이용권 발급을 뜻하지 않게 한다.
부모 확인이 필요한 날에는 아이의 완료 클릭만으로 잠금을 해제하지 않는다.
장식과 격려 문구는 aria-hidden이며 상태 의미는 본문에도 있어야 한다.
배포 경로가 달라지면 CSS 기준의 ../assets 경로를 앱 빌드 방식에 맞게 바꾼다.
이 패키지에는 한 스킨만 있다. 스킨 선택 시스템이나 애니메이션은 이번 제작에 포함하지 않는다.
